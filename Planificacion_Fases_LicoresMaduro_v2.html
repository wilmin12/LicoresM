Introducción

El presente documento describe la planificación de entrega del Sistema de Gestión Interna de Licores Maduro, organizado en cuatro fases de desarrollo. Cada fase agrupa módulos funcionales relacionados y define su estado actual, el trabajo pendiente, el esfuerzo estimado y la fecha proyectada de entrega.

El proyecto tiene como fecha límite de entrega el 30 de junio de 2026, contando con aproximadamente 65 días hábiles de trabajo activo a partir del 1 de abril de 2026. Al momento de elaboración de este documento, el único módulo completado al 100% es M01 – Aankoopbonnen. Todos los demás módulos tienen trabajo pendiente y están distribuidos en el cronograma para concluir dentro del plazo establecido.

Fase 1 – Base + Núcleo Financiero

Módulos: M00 – Platform Base  |  M01 – Aankoopbonnen  |  M03 – Cost Calculation  |  M04 – Freight Forwarders

Descripción general

Esta fase establece los cimientos del sistema. Comprende la autenticación y gestión de usuarios (M00), el módulo de órdenes de compra internas — el único ya completado (M01) —, el cálculo de costos de importación con landed cost (M03) y la gestión de agentes de carga marítima con cotizaciones (M04). El trabajo de esta fase se desarrolla durante el mes de abril de 2026.

Fase 3 – Analítica

Módulos: M05 – Datawarehouse / Analytics

Descripción general

Esta fase implementa la capa de inteligencia de negocios del sistema. El módulo M05 construye un Data Mart en una base de datos separada (DHW_DATABASE) con esquema estrella bajo el patrón SCD Tipo 2 (Slowly Changing Dimensions). Utiliza Pentaho PDI como herramienta ETL para la extracción, transformación y carga de datos, y Power BI como capa de visualización y reportería para los usuarios finales.

Este módulo es el de mayor complejidad técnica del proyecto. La carpeta datawarehouse/ del proyecto contiene los scripts base iniciales. Su desarrollo está planificado para ejecutarse entre finales de mayo y mediados de junio de 2026.
